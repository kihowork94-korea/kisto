# 연구실 이미지 에셋

연구실 화면(`lab.html`)은 지금 코드로 그린 벡터 그림을 쓴다. 이 폴더에 이미지를 넣고
`lab.json`에 적으면 **코드 수정 없이** 그림만 바뀐다. 클릭 영역, 퀘스트 ❗ 표시, 개수 배지,
이름표는 그대로 유지된다.

- 그림을 생성 AI로 만들 거라면 **`prompts/` 폴더**에 에셋별 프롬프트가 준비돼 있다
  (`prompts/README.md`에 만드는 순서와 검수 체크리스트).
- 다 넣은 뒤 `python scripts\check_lab_assets.py`로 크기·비율·투명도를 점검할 수 있다.

## 좌표계

장면 전체는 **960 × 540** 캔버스다 (16:9). 모든 위치·크기는 이 캔버스 기준 픽셀이다.
고해상도로 그리려면 같은 비율로 2배(1920 × 1080) 크기로 만들고 좌표는 그대로 적으면 된다.

## 배경

```json
"background": "room.png"
```

벽·바닥·장식(시계, 화분, 러그)까지 한 장에 그린 이미지. 960 × 540 캔버스 전체를 덮는다.
가구(아래 자리들)는 따로 올라가므로 배경에는 **빈 방**만 그린다.

## 자리별 이미지 (투명 배경 PNG)

```json
"library": { "image": "bookshelf.png", "x": 30, "y": 110, "width": 180, "height": 290 }
```

| 자리 키 | 무엇 | 연결된 연구원 | 지금 벡터 그림의 영역 (x, y, w, h) |
|---|---|---|---|
| `library` | 책장 | 문헌 연구원 | 30, 110, 180, 290 |
| `board` | 퀘스트 보드 (화이트보드) | 프로젝트 진행도 | 250, 45, 230, 160 |
| `laptop` | 책상 + 노트북 | 집필 연구원 | 250, 250, 220, 155 |
| `review` | 검토 보드 (코르크 보드 + 돋보기) | 외부 검토위원 | 520, 55, 190, 135 |
| `bench` | 실험대 + 시험관 + 플라스크 | 분석 연구원 | 500, 250, 230, 150 |
| `team` | 문 (연구원 명단 명패) | 역할 부여 | 780, 150, 130, 250 |

- 위 영역을 크게 벗어나면 이름표·배지·❗ 표시와 겹칠 수 있다. 벗어나야 하면 알려주면 표시 위치를 옮긴다.
- 이미지를 쓰면 그 자리의 **데이터 연출**(책장에 책이 차오름, 시험관에 용액이 참, 검토 보드의 메모지,
  노트북 화면 켜짐)은 꺼진다. 연출까지 이미지로 하려면 상태별 이미지가 필요하다 — 예:
  `"laptop": { "image": "laptop_off.png", "image_active": "laptop_on.png", ... }` (초안이 있으면 on).

## 상태별 이미지가 켜지는 조건

`image_active`는 그 자리에 실제 데이터가 있을 때 대신 보인다 (`lab.js`의 `applyAssets`).

| 자리 | `image_active`가 보이는 때 |
|---|---|
| `library` | 찾아 둔 논문이 1편 이상 |
| `board` | 진행 중인 프로젝트가 1개 이상 |
| `laptop` | 집필 초안이 있음 |
| `review` | 교차검증 기록이 1건 이상 |
| `bench` | 분석 결과가 1건 이상 |
| `team` | (없음 — 문은 항상 기본 이미지) |
