# 생성 AI에 시키는 법 (복붙용 지시문)

폴더를 통째로 올리면 대부분의 도구가 **한 장만 만들고 끝낸다.** 이미지 도구는
"한 번 = 한 장"이라서, 파일을 하나씩 주거나 순서를 정해 줘야 한다.
그래서 `plain/` 폴더를 만들어 뒀다 — **파일 하나 = 이미지 한 장**, 주석도 꺾쇠도 없이
내용을 통째로 복사해 붙이면 되는 형태다.

> 이미 만든 스타일 견본(책장·화이트보드·책상·코르크보드·실험대·문이 한 장에 있는 그림)은
> 지우지 말 것. **그게 1단계 결과물**이고, 나머지 전부의 스타일 레퍼런스로 쓴다.

---

## 1) 폴더를 통째로 올린 경우 — 순서대로 한 장씩 시키기

> 방금 올린 폴더의 `plain` 안에 있는 파일은 **하나가 이미지 한 장**이야.
> 지금부터 **한 번에 한 장씩만** 만들어 줘. 여러 물건을 한 장에 모아 그리지 마.
> 순서는 이렇게:
> `room.png` → `bookshelf.png` → `bookshelf_full.png` → `board.png` → `board_quests.png` →
> `desk.png` → `desk_writing.png` → `review_board.png` → `review_board_notes.png` →
> `bench.png` → `bench_running.png` → `door.png`
> 각 장을 만들기 전에 **어떤 파일인지 이름을 먼저 말해 주고**, 그 파일 내용을 그대로 프롬프트로 써.
> 이미 만든 스타일 견본 이미지를 레퍼런스로 삼아 **같은 그림체·같은 색·같은 광원**을 유지해.
> 한 장 만들고 멈춰서 내 확인을 기다려. 내가 "다음"이라고 하면 이어서 진행해.

## 2) 한 장씩 직접 붙여넣는 경우 (제일 확실하다)

`plain/bookshelf.png.txt`를 열어 **전체를 복사**해 붙이고, 앞에 한 줄만 덧붙인다.

> 첨부한 스타일 견본과 같은 그림체로, 아래 프롬프트대로 **딱 한 장만** 만들어 줘.
> (여기에 파일 내용 붙여넣기)

## 3) 짝이 되는 `_active` 버전 만들 때 (중요)

기본 이미지를 먼저 확정하고, **그 이미지를 첨부한 채로** 시킨다. 새로 그리게 두면
다른 물건이 나와서 화면에서 튄다.

> 첨부한 `bookshelf.png` 이미지를 **그대로 두고** 내용만 바꿔 줘.
> 같은 책장, 같은 각도, 같은 크기, 같은 위치, 같은 색 — 선반이 책과 서류로 가득 찬 버전.
> 구도를 새로 잡지 말고 이 그림을 편집하듯 고쳐 줘.

## 4) 조금만 고치고 싶을 때

> 방금 그림에서 **(고칠 부분)**만 바꿔 줘. 구도·각도·색·그림체는 그대로 유지하고,
> 새로 그리지 말고 이 그림을 수정하는 식으로.

## 5) 투명 배경을 못 만들어 주는 도구라면

그냥 **흰 배경으로 받아도 된다.** 받은 그림을 한 폴더에 모아 파일 이름만
규격 이름(`bookshelf.png`, `desk_writing.png` …)으로 바꾼 뒤:

```
.venv\Scripts\python.exe scripts\prep_lab_assets.py <받은_이미지_폴더>
```

바깥 흰 배경을 지우고(물체 안쪽 흰색은 남긴다), 여백을 자르고, 규격 크기로 맞춰
`widget/lab-assets/`에 저장한다. 그 다음:

```
.venv\Scripts\python.exe scripts\check_lab_assets.py
```

## 자주 나는 문제

| 증상 | 이유 / 대처 |
|---|---|
| 한 장에 여러 물건을 모아 그린다 | 견본(`00_style_sheet`) 프롬프트를 쓴 것이다. `plain/`의 개별 파일로 시킬 것 |
| 그림마다 그림체가 다르다 | 견본 이미지를 레퍼런스로 첨부하지 않은 것이다. 매번 첨부할 것 |
| 기본/활성 두 장이 다른 물건처럼 보인다 | 3번 방식으로, 기본 이미지를 첨부해 "편집"시킬 것 |
| 글자가 들어간다 | "no text, no letters, no numbers"를 한국어로도 덧붙일 것 ("글자·숫자 넣지 마") |
| 크기·비율이 안 맞는다 | 그대로 받아서 `prep_lab_assets.py`로 맞출 것 |
