# ChatGPT에 그대로 복사해 넣는 주문서

`HOW_TO_ORDER.md`가 "왜 한 장씩 시켜야 하는가"라면, 이 파일은 **채팅창에 그대로 붙여넣을 문장**이다.
위에서부터 순서대로 한 메시지씩 보내면 된다.

> **전제**: `00_style_sheet` 프롬프트로 만든 **스타일 견본 한 장**(책장·화이트보드·책상·코르크보드·
> 실험대·문이 흩어져 있는 그림)이 이미 있어야 한다. 없으면 `plain/00_style_sheet.txt`로 먼저 만든다.
> 견본은 `widget/lab-assets/prompts/style_sheet.png`로 저장해 두고 **매 요청마다 첨부**한다.

## 메시지 1 — 규칙 선언 (견본 이미지를 첨부하면서 보낸다)

```
방금 만든 이 그림은 "스타일 견본"이야. 앞으로 만들 그림 전부의 기준이니까 계속 참고해 줘.

지금부터 이 견본에 있는 물건들을 하나씩 따로 떼어서, 총 12장을 만들 거야. 규칙은 이래:

1. 한 번에 딱 한 장만 만든다. 여러 물건을 한 장에 모아 그리지 않는다.
2. 매번 이 견본과 같은 그림체, 같은 색, 같은 광원(왼쪽 위에서 빛, 오른쪽 아래로 그림자),
   같은 정면 각도를 유지한다.
3. 글자, 숫자, 로고, 서명은 절대 넣지 않는다.
4. 배경은 투명(알파 PNG)으로 만든다. 투명이 안 되면 아무것도 없는 순수한 흰 배경으로 만든다.
   배경에 방, 벽, 바닥을 그리지 않는다.
5. 한 장 만들면 멈추고 내 확인을 기다린다. 내가 "다음"이라고 하면 이어서 진행한다.

이해했으면 "준비됐어"라고만 답하고 기다려 줘. 첫 프롬프트는 다음 메시지에 줄게.
```

같은 틀에 파일명과 프롬프트만 바꿔 가며 반복한다.

## `_active` 짝 만들기 — 3·5·7·9·11장째 (**제일 중요**)

**직전에 만든 기본 이미지를 첨부한 채로** 보낸다. 프롬프트 파일을 새로 붙이지 않는다.
새로 그리게 두면 다른 물건이 나와서 화면에서 튄다.

```
방금 만든 <기본 파일명> 이미지를 그대로 두고 내용만 바꿔 줘.
같은 물건, 같은 각도, 같은 크기, 같은 위치, 같은 색 — <바뀔 내용> 버전이야.
구도를 새로 잡지 말고 이 그림을 편집하듯 고쳐 줘. 파일명은 <활성 파일명>.
```

## 중간에 어긋날 때 쓰는 말

| 증상 | 보낼 말 |
|---|---|
| 또 여러 물건을 한 장에 그린다 | `한 장에 한 물건만이야. 방금 건 버리고, <파일명> 하나만 다시 그려 줘.` |
| 그림체가 달라졌다 | `첨부한 견본과 그림체·색·광원이 달라졌어. 견본에 맞춰서 다시 그려 줘.` |
| 글자가 들어갔다 | `그림에 글자가 들어갔어. 글자·숫자·로고 없이 다시 그려 줘.` |
| 배경이 불투명하다 | `배경을 투명하게 해 줘. 안 되면 순수한 흰 배경으로, 방이나 바닥은 그리지 말고.` |
| 물건이 너무 작고 여백이 많다 | `물건이 이미지 가장자리에 거의 닿도록 꽉 채워서 다시 그려 줘.` |

## 다 받은 뒤

1. 받은 그림을 **한 폴더**에 모으고 파일명을 위 표의 규격 이름으로 바꾼다
   (ChatGPT는 파일명을 자기 마음대로 주므로 직접 바꿔야 한다).
2. 흰 배경 제거·여백 자르기·규격 크기 맞추기:
   ```
   .venv\Scripts\python.exe scripts\prep_lab_assets.py <받은_이미지_폴더>
   ```
3. 규격 점검:
   ```
   .venv\Scripts\python.exe scripts\check_lab_assets.py
   ```
4. `prompts/lab.example.json` 내용을 `lab-assets/lab.json`에 덮어쓰면 화면에 반영된다.
   **코드는 고치지 않는다.**

> ChatGPT는 정확한 픽셀 크기(360×580 등)와 투명 배경을 잘 못 맞춘다. **그냥 받아도 된다** —
> 2번 스크립트가 배경 제거와 크기 맞추기를 대신 한다.
