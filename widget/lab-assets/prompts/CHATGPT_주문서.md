# ChatGPT에 그대로 복사해 넣는 주문서

`HOW_TO_ORDER.md`가 "왜 한 장씩 시켜야 하는가"라면, 이 파일은 **채팅창에 그대로 붙여넣을 문장**이다.
위에서부터 순서대로 한 메시지씩 보내면 된다.

> **전제**: `00_style_sheet` 프롬프트로 만든 **스타일 견본 한 장**(책장·화이트보드·책상·코르크보드·
> 실험대·문이 흩어져 있는 그림)이 이미 있어야 한다. 없으면 `plain/00_style_sheet.txt`로 먼저 만든다.
> 견본은 `widget/lab-assets/prompts/style_sheet.png`로 저장해 두고 **매 요청마다 첨부**한다.

## 메시지 1 — 규칙 선언 (견본 이미지를 첨부하면서 보낸다)

```
방금 만든 이 그림은 "스타일 견본"이야. 앞으로 만들 그림 전부의 기준이니까 계속 참고해 줘.

지금부터 이 견본에 있는 물건들을 하나씩 따로 떼어서, 총 12장을 만들 거야. 규칙은 이래:

1. 한 번에 딱 한 장만 만든다. 여러 물건을 한 장에 모아 그리지 않는다.
2. 매번 이 견본과 같은 그림체, 같은 색, 같은 광원(왼쪽 위에서 빛, 오른쪽 아래로 그림자),
   같은 정면 각도를 유지한다.
3. 글자, 숫자, 로고, 서명은 절대 넣지 않는다.
4. 배경은 투명(알파 PNG)으로 만든다. 투명이 안 되면 아무것도 없는 순수한 흰 배경으로 만든다.
   배경에 방, 벽, 바닥을 그리지 않는다.
5. 한 장 만들면 멈추고 내 확인을 기다린다. 내가 "다음"이라고 하면 이어서 진행한다.

이해했으면 "준비됐어"라고만 답하고 기다려 줘. 첫 프롬프트는 다음 메시지에 줄게.
```

```
(여기에 plain/room.png.txt 내용 전체 붙여넣기)
```

## `_active` 짝 만들기 — 3·5·7·9·11장째 (**제일 중요**)

**직전에 만든 기본 이미지를 첨부한 채로** 보낸다. 프롬프트 파일을 새로 붙이지 않는다.
새로 그리게 두면 다른 물건이 나와서 화면에서 튄다.

```

```

# 선택 항목 (12장을 다 넣고 화면을 확인한 뒤)

**중요**: 이 둘은 방 가구와 **그림체가 다르다.** 방 스타일 견본(`style_sheet.png`)을
레퍼런스로 붙이면 안 된다. 각 세트의 **첫 장을 만든 뒤 그 장을 그 세트의 기준**으로 삼는다.

## A. UI 아이콘 5장 (256×256, 투명)

지금은 이모지(❗ ⭐ 🏅 ✅)로 그리고 있다. 순서: `quest_mark` → `star_on` → `star_off`
→ `level_badge` → `stamp_clear`.

### 첫 메시지

```
새 세트를 시작할게. 이번엔 방 가구가 아니라 게임 UI 아이콘이야.
방 스타일 견본은 참고하지 마. 규칙은 같아 — 한 번에 한 장만, 글자·숫자 없이,
투명 배경, 한 장 만들면 멈추고 기다리기.

1장째: 파일명 quest_mark.png, 256x256.

(여기에 plain/quest_mark.png.txt 내용 전체 붙여넣기)
```

### 2·4·5장째 (첫 아이콘을 첨부한 채로)

```
다음. N장째: 파일명 <파일명>, 256x256.
첨부한 quest_mark.png와 같은 그림체, 같은 외곽선 두께, 같은 광원, 같은 여백으로.

(여기에 plain/<파일명>.txt 내용 전체 붙여넣기)
```

### 3장째 `star_off`는 짝이므로 수정 방식으로

```
방금 만든 star_on.png를 그대로 두고 색만 바꿔 줘.
같은 별 모양, 같은 크기, 같은 위치, 같은 외곽선 — 아직 못 받은 빈 별이야.
전체를 납작한 연회색 베이지로 칠하고 반짝임과 하이라이트는 빼 줘.
새로 그리지 말고 이 그림을 편집하듯 고쳐 줘. 파일명은 star_off.png.
```

## B. 연구원 초상 5장 (512×512, 투명)

순서: `avatar_manager` → `avatar_literature` → `avatar_analysis` → `avatar_writing`
→ `avatar_review`.

**매니저(키스토)는 위젯 캐릭터와 같은 인물이어야 한다.** 참고 이미지를
`prompts/character_ref.png`로 뽑아 뒀다 (`idle.mp4`의 3.2초 프레임, 머리~어깨 512×512).
첫 메시지에 **이 이미지를 첨부**한다.

### 첫 메시지 (`character_ref.png` 첨부)

```
또 새 세트야. 이번엔 연구원 초상 5장. 512x512, 투명 배경, 머리와 어깨까지,
얼굴이 가운데. 나중에 원형으로 잘릴 거야.
다섯 장이 한 세트로 보여야 하니까 그림체·머리 크기·광원(왼쪽 위)을 똑같이 맞춰 줘.
한 번에 한 장만, 글자 없이.

1장째: 파일명 avatar_manager.png.
첨부한 이미지가 이 캐릭터야. 같은 인물, 같은 머리색과 머리 모양, 같은 눈,
같은 분위기로 그려 줘. 전신 말고 머리와 어깨만.

(여기에 plain/avatar_manager.png.txt 내용 전체 붙여넣기)
```

### 2~5장째 (`avatar_manager.png`를 첨부한 채로)

```
다음. N장째: 파일명 <파일명>, 512x512.
첨부한 avatar_manager.png와 같은 그림체, 같은 머리 크기, 같은 광원, 같은 채색으로.
다른 사람이지만 같은 세트로 보여야 해.

(여기에 plain/<파일명>.txt 내용 전체 붙여넣기)
```

## 다 받은 뒤

`widget/lab-assets/` 에 규격 이름으로 넣어 두면 된다. `check_lab_assets.py`는
`lab.json`에 등록된 자리 이미지만 보므로 **이 10장은 점검 대상이 아니다** —
화면에 붙이는 건 코드 수정이 필요하니 넣어 두고 알려 주면 된다.

---

## 중간에 어긋날 때 쓰는 말

| 증상 | 보낼 말 |
|---|---|
| 또 여러 물건을 한 장에 그린다 | `한 장에 한 물건만이야. 방금 건 버리고, <파일명> 하나만 다시 그려 줘.` |
| 그림체가 달라졌다 | `첨부한 견본과 그림체·색·광원이 달라졌어. 견본에 맞춰서 다시 그려 줘.` |
| 글자가 들어갔다 | `그림에 글자가 들어갔어. 글자·숫자·로고 없이 다시 그려 줘.` |
| 배경이 불투명하다 | `배경을 투명하게 해 줘. 안 되면 순수한 흰 배경으로, 방이나 바닥은 그리지 말고.` |
| 물건이 너무 작고 여백이 많다 | `물건이 이미지 가장자리에 거의 닿도록 꽉 채워서 다시 그려 줘.` |

## 다 받은 뒤

1. 받은 그림을 **한 폴더**에 모으고 파일명을 위 표의 규격 이름으로 바꾼다
   (ChatGPT는 파일명을 자기 마음대로 주므로 직접 바꿔야 한다).
2. 흰 배경 제거·여백 자르기·규격 크기 맞추기:
   ```
   .venv\Scripts\python.exe scripts\prep_lab_assets.py <받은_이미지_폴더>
   ```
3. 규격 점검:
   ```
   .venv\Scripts\python.exe scripts\check_lab_assets.py
   ```
4. `prompts/lab.example.json` 내용을 `lab-assets/lab.json`에 덮어쓰면 화면에 반영된다.
   **코드는 고치지 않는다.**

> ChatGPT는 정확한 픽셀 크기(360×580 등)와 투명 배경을 잘 못 맞춘다. **그냥 받아도 된다** —
> 2번 스크립트가 배경 제거와 크기 맞추기를 대신 한다.
