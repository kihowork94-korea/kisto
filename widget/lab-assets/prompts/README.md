# 연구실 에셋 생성 프롬프트 모음

연구실 화면(`lab.html`)에 들어갈 그림을 이미지 생성 AI로 **한 세트처럼** 뽑기 위한
프롬프트들이다. 파일 하나 = 에셋 하나. 각 파일 안에 `[STYLE]`(공통 스타일) → `[SUBJECT]`
(그 에셋만의 지시) → `[NEGATIVE]`(부정 프롬프트) 순으로 이미 합쳐 두었으니,
**파일 내용에서 `#`로 시작하는 주석만 빼고 통째로 복사해 넣으면 된다.**

> **도구에 어떻게 시키는지는 `HOW_TO_ORDER.md`를 볼 것.** 폴더를 통째로 올리면 대부분
> 한 장만 만들고 끝난다. `plain/` 폴더에 **파일 하나 = 이미지 한 장**짜리 복붙용 프롬프트가
> 들어 있다 (주석·꺾쇠 없이 그대로 붙여넣는 형태, 크기와 금지사항까지 문장으로 포함).

## 만드는 순서

1. **`00_style.txt`의 `[STYLE SHEET]`로 견본 한 장**을 먼저 만든다. (1024×1024)
   여러 장 뽑아 보고 제일 마음에 드는 것을 고른다.
2. 고른 견본을 **스타일 레퍼런스(이미지 첨부 / style reference / `--sref`)로 지정**하고
   나머지를 전부 만든다. 이게 12장을 같은 세계처럼 보이게 하는 가장 확실한 방법이다.
   같은 도구를 쓴다면 **시드도 고정**해 두면 더 잘 맞는다.
3. `01_room.txt`(배경) → `02`~`12`(가구) 순서로 만든다.
   기본 상태(`02`, `04`, `06`, `08`, `10`)를 먼저 만들고, **그 이미지를 첨부한 채로**
   짝이 되는 `_active` 버전을 만들면 "같은 물건의 다른 상태"가 된다. (이게 제일 중요하다 —
   기본/활성 이미지가 서로 다른 물건처럼 보이면 화면이 튄다.)
4. `13`(UI 아이콘), `14`(연구원 초상)은 선택 사항이다. 있으면 게임 느낌이 확 산다.

크기를 정확히 지정할 수 없는 도구라면 정사각형으로 뽑은 뒤 **여백을 잘라 비율만 맞추면** 된다.

## 넣는 방법

1. 만든 PNG를 `widget/lab-assets/` 에 넣는다 (`prompts/` 폴더가 아니라 그 윗폴더).
2. `prompts/lab.example.json`의 내용을 `widget/lab-assets/lab.json`에 덮어쓰고,
   파일명을 실제로 넣은 이름과 맞춘다. **코드는 고치지 않아도 된다.**
3. 투명 배경이 아니거나 크기가 안 맞으면 다듬는다 (흰 배경 제거 + 여백 자르기 + 규격 크기):
   `.venv\Scripts\python.exe scripts\prep_lab_assets.py <받은_이미지_폴더>`
4. 확인: `.venv\Scripts\python.exe scripts\check_lab_assets.py` (크기·비율·투명도·누락 점검)
5. 화면으로 확인: 백엔드를 띄운 뒤
   `cd widget && node_modules\electron\dist\electron.exe ..\scripts\ui_snapshot.js <세션ID> ..\data\snapshots`

## 검수 체크리스트

- [ ] 투명 배경인가 (흰 사각형이 같이 붙어 오는 경우가 많다)
- [ ] 물체가 이미지 가장자리에 거의 닿게 잘려 있는가 (여백이 크면 화면에서 작아 보인다)
- [ ] 가로:세로 비율이 표와 같은가 (다르면 화면에서 찌그러진다)
- [ ] 글자·숫자·로고·서명이 없는가 (생성 AI가 이상한 글자를 자주 넣는다)
- [ ] 기본/활성 두 장이 **같은 물건·같은 위치·같은 각도**인가
- [ ] 빛이 왼쪽 위에서 오는가, 그림자가 오른쪽 아래인가
- [ ] 바닥에 서는 가구(책장·책상·실험대·문)는 **아래 끝이 바닥에 닿는 면**인가
- [ ] 배경(`room.png`)에 가구가 그려져 있지 않은가, 바닥선이 세로 74% 위치(1080 중 800)인가
- [ ] 25% 크기로 줄여도 뭔지 알아볼 수 있는가
