# 실측 결과 — 이종 모델 교차검증 실증 (2026-09-21)

신청서 3-1·3-2와 발표 자료에 넣을 수치와 사례. 모두 `scripts/e2e.py` 실제 실행 기록이다
(세션 `e2e-20260921-140826`, 상세 원본은 `data/e2e_result.json`·`data/memory_store.json`).

> **분석 단계의 숫자(n=12, r=0.9457 등)는 시연용 가상 데이터로 돌린 결과다.** 실제 측정값처럼
> 발표하지 않는다. 이 문서의 "실측"은 **키스토 시스템의 동작**(시간, 모델 배정, 검토 결과)을 잰 것이다.

## 1. 구성

| 역할 | 모델 | 회사 |
|---|---|---|
| 매니저(라우터·말투), 문헌, 집필 | Claude (Claude Code 하네스) | Anthropic |
| 분석 (코드 작성) | `gpt-5.3-codex` | OpenAI |
| 외부 검토위원 | `gemini-3.8-flash` → 막히면 다른 Gemini → 다른 회사 | Google |

검토위원은 **결과를 만든 회사와 다른 회사 모델**을 코드가 강제로 고른다 (`backend/config.py`).
기록에는 **실제로 답한 모델**이 남는다 — 폴백으로 바뀌어도 거짓 기록이 생기지 않는다.

## 2. 데모 시나리오 결과 (신생아 rPPG vs ECG)

| 단계 | 만든 모델 | 검토한 모델 | 이종검증 | 소요 |
|---|---|---|---|---|
| 1. 주제 탐색 (실제 논문 6편 검색) | Claude | **Gemini** | **O** | 82초 |
| 2. 분석 (코드 작성·실행·해석) | **GPT** | Claude | **O** | 90초 |
| 3. 해석 질문 (대필 금지 — 먼저 묻기) | Claude | 없음 (검토할 결과가 없는 단계) | – | 12초 |
| 4. 서론 초안 (연구자 해석 반영) | Claude | **GPT** | **O** | 107초 |
| **합계** | **3사 모두 참여** | | **3/3 (100%)** | **292초 (4분 52초)** |

- 로드맵: 0 → 40% → 80% → 80% → 100% (저장된 실데이터로만 판정)
- 대시보드: **다른 회사 모델 검토 비율 100% (3/3)**
- 같은 시나리오의 소요 시간 추이: 435초(9/18, 순차) → 297초(9/18, 검토·말투 병렬화) → **292초(9/21, 3사 구성)**

### 오늘 같은 날 네 번 돌린 기록 (안정성 참고)

| 실행 | 이종검증 | 비고 |
|---|---|---|
| 1차 | 1/3 | Gemini 503(요청 폭주), OpenAI 모델 404 → 폴백 없이면 대화가 500으로 끊겼을 상황 |
| 2차 | 2/3 | 재시도 추가 후. Gemini 503이 14초 넘게 지속된 단계만 X |
| 3차 | – | (OpenAI 크레딧 충전 전 점검) |
| **최종** | **3/3** | 같은 회사 안 다른 Gemini 모델로 먼저 넘어가게 한 뒤. 4단계는 Gemini 무료 한도(429) → GPT가 검토 |

→ **교훈**: 외부 API는 실제로 자주 막힌다. 호출 단위 폴백과 "실제로 답한 모델" 기록이 없으면
교차검증 수치 자체를 믿을 수 없다. 발표 당일에는 Gemini 유료 등급(또는 한도 여유) 권장.

## 3. 검토위원이 실제로 잡아낸 오류 (발표 사례용)

세 검토 모두 "지적 있음". 결과를 만든 모델이 **자기 결과에서 놓친 것**을 다른 회사 모델이 짚었다.

**① 문헌 정리 (Claude가 씀 → Gemini가 검토)**
- 근거 논문 [2]의 **NIRS는 피부에 센서를 붙이는 접촉식**인데 "비접촉" 기술로 잘못 설명함
- "신규 데이터 없이 시작하기 쉽다"는 실현 가능성 과대평가 — 신생아 영상은 개인정보·윤리 문제로 공개 데이터가 드묾
- 논문 [3] 초록에 이미 있는 "자세 기반 움직임 감지"를 빠뜨리고 연구 공백처럼 서술함

**② 분석 (GPT가 씀 → Claude가 검토)**
- **피어슨 r은 "일치도"가 아니라 "연관성" 지표** — r=0.95를 근거로 측정 일치를 주장하는 건 Bland-Altman 방법론이 경고하는 과대해석
- n=12에서 편향의 신뢰구간이 제시되지 않음

**③ 서론 초안 (Claude가 씀 → GPT가 검토)**
- ①에서 지적된 **"NIRS 비접촉" 오류가 초안에 그대로 남아 있음**을 다시 잡음
- 인용 [6](색변화 바이오마커 센서 논문)이 "유선 센서가 불편하고 이상 징후를 놓친다"는 문장의 근거로는 맞지 않음
- 반복측정 구조에서 상관계수가 부풀려질 가능성

> 같은 오류(NIRS)를 두 검토위원이 서로 다른 단계에서 독립적으로 잡았다. 한편 이 오류가 초안까지
> 이어졌다는 건, 검토 노트가 **자동 수정이 아니라 연구 책임자에게 보이는 노트**라는 설계 때문이다
> (최종 판단은 연구자 — 설계 결정 5). 초안 단계에 이전 검토 지적을 넘겨 주는 건 개선 후보.

## 4. 실제 논문만 인용 (환각 방지)

- 문헌 연구원이 **PubMed에서 실제 검색한 논문 6편** (2026년 발표분, 예: *Video-based artificial intelligence
  for automated neonatal respiratory monitoring*, Eur J Pediatr)
- 초안은 이 목록의 번호로만 인용 ([2], [6]) — 참고문헌 목록은 모델이 아니라 **코드가** 붙인다
- 근거 논문이 없는 주장에는 모델이 인용을 지어내지 않고 **`[참고문헌 필요]`**로 남겼다
  ("미숙아 피부 손상" 문장)

## 5. 대필 금지 동작

3단계에서 집필 연구원이 초안을 바로 쓰지 않고 **연구자의 해석을 먼저 물었고**(12초),
4단계 초안은 연구자가 답한 해석("보조 수단으로 가능성, 다만 n=12·통제 환경 한계, 서론에서는
전극 부착의 피부 손상을 강조")을 반영했다.
