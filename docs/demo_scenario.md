# 시연영상 대본 — 신생아·영유아 비침습 연구

> 신청서 첨부용 시연영상(권장 3분 30초 내외) 대본. 입력 문장은 `scripts/e2e.py`의 STEPS와 같다.
> **분석 단계의 심박 데이터는 시연용 가상 데이터**다. 영상 자막에도 "가상 데이터"라고 표시한다.

## 촬영 전 준비

1. `.env`에 OpenAI·Gemini 키를 넣는다 → 교차검증이 다른 회사 모델로 돈다 (핵심 차별점).
   키 없이 찍으면 응답이 1~3분씩 걸리고 교차검증도 같은 회사 모델끼리가 된다.
2. `run.cmd` 더블클릭 → 위젯이 바탕화면 오른쪽 아래에 뜬다.
3. 트레이 메뉴 → **새 대화 세션 시작** (로드맵이 빈 상태에서 시작해야 단계가 차오르는 게 보인다).
   이어서 트레이 메뉴 → **발표 모드** 켜기 (답변마다 에이전트·회사 모델 흐름이 보인다 — 핵심 차별점).
4. 바탕화면을 깔끔하게 정리하고, 화면 녹화는 전체 화면으로.
5. 응답 대기 구간은 편집에서 빨리감기하고 "실제 소요 N분" 자막을 단다 (시간 단축 성과의 근거).

## 장면 구성

| # | 시간 | 화면 | 입력 / 동작 | 보여줄 포인트 (자막·내레이션) |
|---|---|---|---|---|
| 0 | 0:00–0:15 | 바탕화면 + 캐릭터 | 캐릭터를 드래그해 옮기고, 클릭해서 대화창 열기 | "파편화된 AI 챗 대신, 바탕화면에 사는 연구 동료 한 명" |
| 1 | 0:15–0:50 | 대화창 | **①** 아래 입력 1 | **실제 논문 [번호] 인용 + 참고 논문 목록**, 되묻는 질문, 발표 모드 흐름(`문헌 검색 · PubMed/OpenAlex N편`), 로드맵 **2단계까지 클리어 연출** |
| 2 | 0:50–1:40 | 대화창 | **②** 📎로 CSV 첨부 후 "이 데이터로 분석해줘" (또는 아래 입력 2) | 생각 중 말풍선 → 코드 실행 결과(MAE·r·Bland-Altman) → 해석, **🔍 검토 노트를 펼쳐** 다른 회사 모델의 지적을 보여줌, 로드맵 **4단계 클리어** |
| 3 | 1:40–2:10 | 대화창 | **③** 아래 입력 3 | 초안을 바로 주지 않고 **연구자의 해석을 먼저 묻는 장면** (대필하지 않음 = 연구윤리) |
| 4 | 2:10–2:50 | 대화창 | **④** 아래 입력 4 | 해석을 반영한 서론 초안 + 짧은 검토 조언, 로드맵 **5/5 완주 연출** |
| 5 | 2:50–3:20 | 🏠 연구실 | 로드맵의 **🏠 연구실** 클릭 → 서재(실제 논문) → 검토 보드(다른 회사 검토 기록) → 연구원 명단(역할 부여) 순서로 누르기 | "연구자는 매니저 한 명과 대화하고, 연구원들은 뒤에서 일한다" — 책장·시험관·메모지가 실제 기록만큼 차 있는 것, ❗ 퀘스트 표시, 연구실 레벨 |
| 6 | 3:20–3:30 | 💻 노트북 | **📓 연구노트로 내보내기** → 저장된 연구노트 열기 | "주제 잡기부터 초안·연구노트까지, 실측 N분" |

## 입력 문장

**① 주제 탐색**
> 신생아랑 영유아 대상으로 비침습 연구를 해보고 싶은데, 신입이 시작할 만한 연구 주제를 어떻게 잡으면 좋을까?

**② 분석 (가상 데이터)**
> 카메라 기반 비접촉 심박 측정(rPPG) 데이터로 분석 돌려줘. 신생아 12명의 같은 시점 심박수(bpm)야. 심전도(ECG) 기준값은 142, 128, 155, 136, 149, 131, 160, 138, 145, 152, 127, 140 이고, 카메라(rPPG) 측정값은 145, 125, 151, 139, 147, 135, 156, 141, 149, 148, 131, 137 이야. 평균 절대 오차, 피어슨 상관계수, Bland-Altman 편향과 95% 일치 한계를 계산해서 카메라 측정이 ECG를 대신할 수 있는지 봐줘.

가상 데이터의 정답값 (결과 화면 검수용): MAE 3.42 bpm, r = 0.946, 편향 +0.08 bpm, 95% 일치 한계 −7.0 ~ +7.2 bpm

**③ 집필 요청**
> 이 결과를 논문 서론에 녹여서 초안 써줘.

**④ 연구자 해석**
> 제 해석은 이렇습니다. 편향이 거의 0이고 일치 한계가 ±7bpm 정도라, 카메라 측정이 신생아 심박 모니터링의 보조 수단으로는 가능성이 있다고 봅니다. 다만 12명뿐이고, 조명과 움직임이 통제된 환경에서 잰 값이라 실제 신생아 중환자실 조건이나 다양한 피부톤에서도 같을지는 모릅니다. 서론에서는 전극 부착이 미숙아 피부 손상과 스트레스를 일으킨다는 문제를 비침습 측정이 필요한 이유로 강조하고 싶습니다.
